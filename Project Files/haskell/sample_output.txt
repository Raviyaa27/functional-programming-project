== Part C: simplify (before  ->  after) ==
  x * 1 + 0                         ->  x
  let a = x + 0 in a * 1 * y        ->  let a = x in a * y
  2 * 3 + x * 0                     ->  6
  x + y - (x + y)                   ->  0
  if 1 < 2 then x / 1 else y        ->  x
  let unused = 9 in x + y           ->  x + y
  1 / 0                             ->  1 / 0
  w * 0                             ->  0
  note: 1 / 0 is left for eval to report; w * 0 -> 0 also drops the
        'undefined variable' error, so simplify preserves successful
        results only (see Props.hs and the report, Part E).
